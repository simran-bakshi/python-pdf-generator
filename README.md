# python-pdf-generator
This Python-based tool allows you to merge multiple images into a single PDF file. It supports various image formats such as JPEG, JPG and PNG. Whether you're looking to combine a collection of photos or create a single PDF from a set of scanned pages, this script makes it easy to do so.
<br>
## Libraries Used:
This project requires the following libraries:
- **Tkinter**: For creating the graphical user interface (GUI).
- **ReportLab**: For generating the PDF.
- **Pillow (PIL)**: For handling images (resizing, loading, etc.).
- **OS**: For interacting with the file system (e.g., handling file paths).
